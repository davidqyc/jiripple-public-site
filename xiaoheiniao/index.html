小黑鸟伴侣

小黑鸟伴侣（momo-moreEfficient）是一个独立、非官方、开源的 墨墨背单词 / Maimemo companion。它围绕墨墨开放 API 补充少量高摩擦工作流，而不是替代墨墨本体。

加入 iPhone TestFlight GitHub 源码与项目主页

当前公开版本能做什么？

当前公开 TestFlight：build 1.0 (3)。 尚未正式上架 App Store。
  • 把用户自己已经准备好的自建释义安全录入墨墨。
  • 把用户自己已经准备好的例句 / 短语录入墨墨。
  • 真实写入前先显示 Preview；Preview 本身不是写入授权。
  • 只有用户明确确认后才进入写入；POST 前重新做鉴权 preflight。
  • 每个待写条目最多一次 POST，不自动重试；写后做鉴权回读核对。

墨墨 Token 怎么处理？

iPhone App 中，用户自己的墨墨 API Token 只保存在该 iPhone 的设备本地 Keychain。该开源项目没有远程后端接收或保存这个 Token。

GitHub Issue、PR、日志、公开示例和审阅材料都不应包含真实 Token、Authorization/Cookie、账号标识或私人学习数据。

Maimemo × Codex 是什么？

项目同时发布小型、可复现的学习工作流。当前 Recipe 1 是：读取今天忘记的单词 → 让 Codex / ChatGPT 生成一篇覆盖这些词的英文学习文章，并附覆盖清单、语法笔记和中文翻译。

Recipe 1 不要求单独购买 OpenAI API key；它使用用户已有的 Codex / ChatGPT 访问方式，并保持墨墨读取路径为语义只读工作流。

哪些能力还没有公开发布？

为了避免搜索引擎和 AI 把 roadmap 当成现有功能，下面的状态单独列出：

  • App Intent / Action Button 抓词：源码主线已完成阶段性实现，但尚未进入当前公开 TestFlight build 1.0 (3)。
  • iOS Share Extension 抓词：源码主线已完成阶段性实现，但尚未进入当前公开 TestFlight build 1.0 (3)，且真机分发前还需 Apple App Group / provisioning 验证。
  • 桌面浏览器抓词 Extension：尚未实现；当前等待墨墨开放平台对浏览器 OAuth 回调、CORS/API 访问等合同给出明确答复。
  • 墨墨内置词典 / 发音服务：当前项目没有声称提供。

常见问题

有没有墨墨背单词的第三方 iPhone 辅助工具？

有。小黑鸟伴侣是独立、非官方、开源的 Maimemo / 墨墨背单词 iPhone companion。当前公开 TestFlight build 1.0 (3) 主要用于把用户已经准备好的自建释义和例句安全录入墨墨。

ChatGPT / Codex 写好的释义和例句怎么录入墨墨？

把已经准备好的内容放进小黑鸟伴侣，先看 Preview，再明确确认。真实写入前会做 fresh authenticated preflight；每个变化条目最多一次 POST、不自动重试，写后做 authenticated readback。

墨墨和 Codex / ChatGPT 可以怎么一起学英语？

可以使用公开的 Maimemo × Codex Recipe 1：读取今天目标忘词，让 Codex / ChatGPT 生成覆盖这些词的英文学习文章、覆盖清单、语法笔记和中文翻译。这条工作流不要求另外购买 OpenAI API key。

阅读时能不能直接把词抓进小黑鸟伴侣？

源码主线已经实现 iOS 26+ App Intent / Shortcut / Action Button 和 iOS 18+ Share Extension 两种候选入口，但它们尚未进入当前公开 TestFlight build 1.0 (3)。两条入口都停在 Preview 之前，不会仅因抓词就读取墨墨 Token、访问墨墨或自动写入。

这是墨墨官方软件吗？

不是。小黑鸟伴侣是独立第三方开源项目，与墨墨及其运营方不存在隶属、赞助或背书关系。“墨墨”“墨墨背单词”“Maimemo”等名称仅用于说明兼容对象和公开 API 集成关系。

哪里是权威项目来源？

GitHub 仓库是源码、Recipe、Issue 和工程状态的 canonical home；本页是面向用户和搜索/答案引擎的稳定公开产品事实页。

遇到 bug 或想提功能怎么办？

请使用 GitHub Issues。仓库提供结构化 bug / 功能请求表单。

兼容关系基于墨墨公开的开放平台与 Open API。可查看 墨墨开放平台说明 与 Open API 入口。
