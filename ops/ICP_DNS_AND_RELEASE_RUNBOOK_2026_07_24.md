## 备案整改：唯一允许暂停的记录

备案重新提交前，只暂停：

```text
主机记录：www
记录类型：CNAME
记录值：davidqyc.github.io.
```

严禁暂停、删除或修改：

- 两条 `@` MX 记录；
- `@` TXT / SPF 记录；
- 任何 DKIM、DMARC、域名验证记录；
- NS 服务器；
- 与企业邮箱相关的其他记录。

当前基线中不存在用于网站访问的 `@` A / AAAA / CNAME 记录，因此本轮只暂停了 `www` CNAME。

## 备案通过后的执行顺序

### E2. DNS 恢复前先修改网站页脚

1. 在 `davidqyc/jiripple-public-site` 中加入网站服务备案号：

```text
辽ICP备2024033740号-2
```

2. 备案号必须链接至：

```text
https://beian.miit.gov.cn/
```

3. 首页、ReliableReader 产品页和隐私政策页应共享一致的合规页脚；
4. 不在网站页脚加入 APP 备案编号；
5. 本地构建和静态产物检查通过后部署 GitHub Pages；
6. DNS 仍保持暂停，避免未完成合规页脚时提前恢复公网。

### E3. 恢复网站解析

1. 在旧腾讯云账号恢复：

```text
主机记录：www
记录类型：CNAME
记录值：davidqyc.github.io.
TTL：600
```

2. 等待至少一个 TTL 周期；
3. 使用两种独立客户端确认：
   - 首页恢复；
   - ReliableReader 产品页恢复；
   - 隐私政策页恢复；
   - HTTPS 正常；
   - 页面标题仍为 `坐等唯美艺术生活｜JiRipple 产品与服务`；
   - 网站服务备案号 `辽ICP备2024033740号-2` 正确显示并可点击。

### E4. 公安联网备案

1. 自网站恢复并实际开通服务起，按腾讯云页面和属地公安要求办理公安联网备案；
2. 使用腾讯云生成的数据码继续流程；
3. 完成后，在网站页脚加入公安备案号与对应查询链接；
4. 不把公安数据码当成最终公安备案号公开展示。

5. 完成中国大陆账户级合规信息；
6. 完成旧账号 CloudBase → 新公司账号环境切换；
7. 用生产 Harness、双客户端、正反向测试、自动修复循环和独立 release gate 完成验证；
8. 旧 CloudBase 环境保留兼容期，直到旧 Build 无实际流量。

## 备案完成后的账号归并

网站恢复并确认稳定后，再处理账号归并：

1. 将 `jiripple.com` 的域名注册管理权和 DNS 解析从旧腾讯云账号迁移到新公司账号；
2. 若域名注册与 DNS 可一起转移，优先一次完成；
3. 迁移前导出当前 DNS 记录；
4. 迁移后核对 MX、SPF、DKIM、DMARC、网站 CNAME、自动续费和扣费账户；
5. 完成独立 DNS 与 HTTP 验证后，才把旧账号从日常运维链路中移除。
