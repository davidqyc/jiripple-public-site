## 域名与 DNS 账号归并

公安联网备案完成、网站恢复并确认稳定后，再处理账号归并，避免同时打开多个风险面。

优先路径：在旧腾讯云账号的“域名注册”中进行账号间转移，并选择：

```text
同时转移域名注册及 DNS 解析
```

这样将一次转移：

- 域名注册管理权；
- 后续续费管理入口；
- 当前 DNS 解析记录；
- 如存在的 DNS 解析套餐和增值服务。

执行前必须：

1. 确认新公司主账号允许接收域名；
2. 取得新公司主账号的账号 ID 与 APPID；
3. 导出或截图当前完整 DNS 记录；
4. 确认域名不处于续费、赎回、实名修改、命名审核、转出或锁定状态；
5. 记录当前自动续费设置、到期时间和扣费方式。

执行后必须复核：

- 域名仍使用原实名信息与所有者；
- 自动续费设置和到期提醒是否保留；
- 新账号余额或支付方式足以承担后续续费；
- MX、SPF、DKIM、DMARC 与网站 CNAME 完整存在；
- 网站、产品页、隐私页、企业邮箱均正常；
- 旧账号已失去该域名的注册与 DNS 管理权。

若旧账号中只有 DNS、没有域名注册，则改用云解析 DNS 的“账号间转移”，不得使用“域名取回”，因为取回可能重置 DNS 并中断服务。
